# ICDE 2027 Tutorial — Data Engineering Design Patterns

Companion repository for the ICDE 2027 tutorial proposal
**"Data Engineering Design Patterns: Ingestion, Transformation, Environment Promotion, and LLM-Generated Pipelines"**
by Motaz K. H. Saad, Chiara Rucco, and Antonella Longo (University of Salento).

## Contents

- `slides/` — LaTeX source and PDF preview of the tutorial slides (`tutorial-preview.tex`, `tutorial-preview.pdf`).
- `lab/` — Hands-on lab materials:
  - `demo_mind.py` — metadata-driven ingestion (MIND) demo.
  - `demo_eltl.py` — ETLT/ELTL architectural-pattern demo.
  - `demo_eadf.py` — Environment-Aware Design Pattern (EADF) promotion demo.
  - `connectors.json`, `metadata-table.csv` — fixtures used by the demos.
  - `README.md` — lab instructions and prerequisites.

The full tutorial proposal (PDF/LaTeX) lives in the parent repository.
Slides and the lab setup guide will be updated here before the conference.
