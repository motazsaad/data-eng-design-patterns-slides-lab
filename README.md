# Tutorial — Data Engineering Design Patterns

Companion repository for the tutorial proposal
**"Data Engineering Design Patterns: Ingestion, Transformation, Environment Promotion, and LLM-Generated Pipelines"**
by Motaz K. H. Saad, Chiara Rucco, and Antonella Longo (University of Salento).

## Description
This repository contains the slide deck (tutorial-preview.tex, tutorial-preview.pdf) and hands-on lab materials for the tutorial proposal. It includes:
- Demo scripts for MIND ingestion, ETLT/ELTL patterns, and EADF promotion.
- Fixture files (metadata-table.csv, connectors.json) used in the demos.
- Setup guide and instructions for attendees.
